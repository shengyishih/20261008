# Block After Dark

A responsive, no-build Tetris arcade game. Open `index.html` locally or deploy this folder as a Hugging Face Static Space.

## Controls

- ← / →: move
- ↑ or X: rotate
- ↓: soft drop
- Space: hard drop
- P or Escape: pause

Touch controls are available on small screens. Best score is saved in browser local storage.
